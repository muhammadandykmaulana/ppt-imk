Eduverse Store

Design Case Study: Platform Edukasi Parenting Islami

Evaluasi Usability & Perancangan Interaksi Manusia-Komputer

INSTITUT TEKNOLOGI TANGERANG SELATAN (ITTS) - 2026

Latar Belakang (Empathize)

Masalah Usability Saat Ini

Komunitas parenting Islami sering berbagi materi via grup WA atau Medsos. Dari sudut pandang IMK, ini menimbulkan hambatan kognitif: pencarian konten tidak terstruktur, transaksi manual tanpa feedback sistem, dan sulitnya melacak riwayat pembelian produk digital.

Solusi: Eduverse Store

Aplikasi web berbasis React JS yang memecahkan masalah kebergunaan melalui antarmuka terpusat untuk edukasi, checkout mandiri terintegrasi (QRIS), dan pelacakan riwayat akses materi secara terstruktur.

Tujuan Studi Kasus (IMK)

  • Menggali kebutuhan riil pengguna melalui wawancara dan observasi.
  • Merumuskan persona dan memetakan hambatan kognitif pengguna (User Journey).
  • Membangun prototipe high-fidelity yang responsif dan memperhatikan aspek aksesibilitas.
  • Mengukur tingkat kebergunaan secara kuantitatif melalui System Usability Scale (SUS) dan kualitatif via Evaluasi Heuristik.

Pemenuhan Kriteria Penilaian UAS

Proyek ini dikembangkan selaras dengan panduan penilaian akhir mata kuliah IMK.

Kriteria Penilaian Bobot Implementasi dalam Proyek Ini
Validitas Riset 25% Melakukan riset primer (wawancara riil) terhadap 3 responden target (Ibu Rumah Tangga & Pengelola Yayasan), menghasilkan 3 User Persona spesifik, dan memetakan User Journey.
Kualitas Desain & Interaksi 30% Membangun prototipe High-Fidelity dengan framework React JS. Menerapkan konsistensi warna (Emerald/Orange), hirarki visual, dan respon interaktif (hover, modal QRIS).
Metodologi Evaluasi 25% Melakukan pengujian System Usability Scale (SUS) via Google Form kepada partisipan nyata dan melakukan Audit Heuristik (Nielsen's 10 Heuristics) secara mandiri.
Aksesibilitas & Inklusivitas 20% Mengadopsi ukuran target ketuk yang ramah mobile (mobile-first), menyediakan palet warna dengan kontras memadai, dan mempertimbangkan pengguna lansia/awam digital.

Define: User Personas

Berdasarkan wawancara lapangan (memenuhi kriteria Validitas Riset 25%).

Bu Rema

"Ibu Muda yang Mencari Kepastian"

Latar: Ibu rumah tangga, anak usia 3 thn.

Frustrasi: Ragu bertransaksi digital mandiri, takut salah tekan.

Kebutuhan UI: Badge harga jelas, modal QRIS yang meyakinkan & membimbing.

Bu Silfi

"Pengelola Yayasan yang Ingin Mandiri"

Latar: Pengelola Yayasan Zait bin Tsabit.

Frustrasi: Distribusi via WhatsApp berantakan, file materi sering hilang.

Kebutuhan UI: Panel Admin terstruktur, kategori konten jelas, rekap pesanan.

Bu Iqlim

"Pendidik Dua Rentang Usia"

Latar: Pengajar TK & Ibu 2 anak beda usia.

Frustrasi: Bingung bedakan alur checkout web internal vs marketplace luar.

Kebutuhan UI: Label penanda tipe checkout yang kontras, filter berdasarkan usia.

Problem Statement (How Might We)

Bagaimana caranya agar pengguna baru (ibu rumah tangga) merasa yakin saat melakukan checkout QRIS mandiri, dan dapat membedakan dengan jelas antara produk internal dan eksternal sebelum menekan tombol?

Ideate: Task Analysis (HTA) & Solusi

Hierarchical Task Analysis

0. Membeli Produk Digital

  • 1. Membuka halaman Katalog Produk
  • 2. Memilih produk (kategori/usia anak)
  • 3. Menekan tombol beli sesuai tipe produk
    • 3.1 Jika internal: memindai QRIS & bayar
    • 3.2 Jika eksternal: ikuti link marketplace
  • 4. Menunggu verifikasi admin (khusus internal)
  • 5. Membuka akses digital di halaman Profil

Ide Solusi Antarmuka

  • Kartu Produk: Menampilkan badge status, harga coret, dan label/ikon tipe checkout secara visual agar meminimalisir error.
  • Modal QRIS: Didesain dengan nominal tertera besar dan instruksi ringkas mengurangi keraguan persona Bu Rema.
  • Halaman Profil: Berfungsi ganda sebagai tempat mengunduh file dan melihat riwayat (solusi untuk Bu Silfi & Bu Iqlim).
  • Tema Visual: Adaptif (Mode Terang/Gelap) menggunakan CSS variables.

Evaluate: System Usability Scale (SUS)

Mengukur tingkat kebergunaan secara kuantitatif (Memenuhi kriteria Metodologi Evaluasi 25%).

Responden Latar Belakang Profil Skor SUS Grade (Adjective) Status Acceptability
Bu Rema Ibu rumah tangga (awam digital) 77.5 C+ (Good) Acceptable
Bu Silfi Pengelola Yayasan (terbiasa sistem) 92.5 A+ (Excellent) Acceptable
Bu Iqlim Pengajar TK (multi-tasking) 65.0 D (OK / Marginal) Marginal
RATA-RATA SKOR KESELURUHAN: 78.33 C+ / B- (Good) Acceptable

Insight Kualitatif:

Skor marginal pada Bu Iqlim (65.0) mengkonfirmasi hipotesis awal bahwa ketiadaan ikon/warna pembeda yang sangat kontras antara checkout internal (QRIS) dan eksternal menyebabkan kebingungan kognitif saat bertransaksi.

Aksesibilitas & Evaluasi Heuristik

Tinjauan Aksesibilitas (WCAG)

Memenuhi Kriteria Penilaian UAS 20%

  • Kontras Warna: Palet utama hijau (Emerald) cukup kontras. Perlu perbaikan minor pada teks sekunder abu-abu.
  • Target Ketuk (Mobile): Tombol utama (checkout, login) berukuran besar dan aman untuk jari (Touch-friendly). Ikon tabel admin masih agak rapat.
  • Ramah Awam: Didukung antarmuka minimalis, namun perlu tambahan tooltip/microcopy panduan di modal QRIS.

Temuan Heuristik (Severity > 2)

Evaluasi Mandiri (Nielsen's 10 Heuristics)

  • Pencegahan Kesalahan (Sev 3): Risiko salah tekan antara produk internal vs eksternal akibat label kurang mencolok.
  • Status Sistem (Sev 2): Tidak ada indikator "Menunggu Verifikasi" yang eksplisit di halaman profil setelah scan QRIS.
  • Kontrol Pengguna (Sev 2): Ketiadaan tombol "Batal/Tutup" yang sangat menonjol saat Modal QRIS sudah terbuka.

Kesimpulan Studi Kasus

Kesimpulan

Prototipe Eduverse Store berhasil memecahkan masalah kebergunaan terkait distribusi materi edukasi. Hasil uji SUS (78.33 - Acceptable) membuktikan antarmuka dapat diterima dengan baik oleh target pengguna (ibu rumah tangga & pendidik), meskipun memerlukan beberapa penyesuaian kognitif.

Rekomendasi Iterasi UI Selanjutnya

  • Mengubah warna/ikon tombol checkout untuk membedakan secara tegas produk internal vs eksternal.
  • Menambahkan microcopy / tooltip panduan singkat ("Cara Bayar") di dalam Modal QRIS.
  • Memperbesar target ketuk (padding) pada tabel dashboard admin untuk aksesibilitas mobile.
